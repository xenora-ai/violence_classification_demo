# Violence Classification System

## Опис проєкту
Цей репозиторій містить програмний прототип інтелектуальної системи комп'ютерного зору для виявлення та класифікації аномальних подій (актів насильства) у відеопотоках. Проєкт розроблено в рамках дослідження згорткових та рекурентних нейромережевих архітектур для просторово-часового аналізу відеоданих.

Система аналізує відео з веб-камери або завантажених файлів, виявляючи агресивні дії з мінімальною затримкою, що дозволяє використовувати її для завдань автоматизованого моніторингу безпеки.

## Архітектура та оптимізація
В основі системи лежить гібридна архітектура CNN+LSTM:

* **Spatial Feature Extraction (CNN):** Використовується оптимізована згорткова мережа MobileNetV2. Вона діє як екстрактор ознак, перетворюючи кожен кадр на вектор розмірності 1280.
* **Temporal Modeling (LSTM):** Рекурентна нейронна мережа аналізує послідовність отриманих векторів для розуміння динаміки та часового контексту дій.

Методи оптимізації інференсу:
1. **Кільцевий буфер (Ring Buffer):** Використання структури deque для зберігання останніх N кадрів (контекстного вікна). Це нівелює необхідність перераховувати ознаки для всього відеоряду щоразу.
2. **Асинхронний інференс:** Обчислення рекурентного блоку винесено в окремий потік (threading), що запобігає блокуванню головного циклу рендерингу інтерфейсу.
3. **Frame Skipping:** Пропуск кадрів (аналізується кожен 3-й кадр) для зменшення навантаження на процесор при збереженні достатньої темпоральної роздільної здатності.

## Структура репозиторію
* app.py — головний файл запуску веб-інтерфейсу на базі Streamlit.
* src/model.py — ініціалізація та опис гібридної архітектури класу CNNLSTM.
* src/utils.py — допоміжні функції для попередньої обробки кадрів (нормалізація ImageNet) та відмальовування інтерфейсу (HUD).
* weights/ — директорія для збереження ваг навченої моделі (.pt).
* requirements.txt — перелік необхідних залежностей середовища.

## Вимоги до середовища
Для коректної роботи системи потрібен встановлений Python 3.9 або новішої версії.

## Встановлення та запуск

1. **Клонування репозиторію**
```bash
git clone <посилання_на_репозиторій>
cd violence_detection_project
```

2. **Створення та активація віртуального середовища**
Для Windows:
```bash 
python -m venv venv
venv\Scripts\activate
```

Для Linux/macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```

3. **Встановлення залежностей**
```bash
pip install -r requirements.txt
```

4. **Запуск застосунку**
```bash 
streamlit run app.py
```

Після виконання команди застосунок автоматично відкриється у локальному браузері.

## Використання
В інтерфейсі користувача доступні такі налаштування:
* **Джерело даних:** Вибір між трансляцією з веб-камери або аналізом попередньо завантаженого MP4 файлу.
* **Поріг (Threshold):** Налаштування чутливості класифікатора (від 0.3 до 0.9).
* **Stack Size:** Розмір вікна пам'яті моделі (кількість кадрів, які одночасно подаються в LSTM). Менше значення (наприклад, 8) забезпечує вищу швидкість реакції, більше (32) — глибший часовий контекст.
